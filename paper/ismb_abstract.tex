\section{Background}

Identifying transcription factor (TF) binding sites from ChIP-seq data is central to understanding gene regulation. Deep learning approaches such as BPNet~\cite{avsec2021} and ChromBPNet~\cite{chrombpnet2021} achieve high accuracy but rely on post-hoc attribution (DeepSHAP, TF-MoDISco) for interpretation. This predict-then-interpret paradigm introduces attribution artifacts, requires manual motif curation, and cannot directly enumerate discrete binding events within a regulatory region.

We present \textbf{BEACON} (\textbf{B}inding \textbf{E}vent \textbf{A}ttention-based \textbf{C}ompositional \textbf{O}bject \textbf{N}etwork), which reconceptualizes TF binding site discovery as an object-centric decomposition problem. Inspired by slot attention~\cite{locatello2020}, BEACON treats each binding event as a discrete object with genomic position, TF identity, and occupancy strength, directly decomposing regulatory sequences into constituent binding events through competitive attention---providing inherent interpretability while improving predictive accuracy.

\section{Methods}

BEACON consists of four components. (1)~A \emph{dilated CNN backbone} ($2^0$--$2^8$ dilation rates, 1029\,bp receptive field) encodes one-hot DNA sequences ($L{=}2000$\,bp), capturing both local motif patterns and long-range cooperativity. (2)~A \emph{helical positional encoding} captures the 10.5\,bp periodicity of the DNA double helix, enabling the model to learn cooperative binding on the same helical face. (3)~$K{=}16$ learnable \emph{slot vectors} compete for sequence positions via $T{=}3$ iterations of slot attention with per-slot softmax and GRU updates; this independent attention mode allows multiple slots to activate simultaneously for multi-TF sequences. (4)~\emph{Per-slot heads} predict binding site position (Gaussian $\mu, \sigma$), TF identity (softmax), and occupancy (sigmoid). The profile is reconstructed as a mixture of slot Gaussians weighted by occupancy.

Training uses a composite loss: profile reconstruction (KL + MSE), Hungarian-matched~\cite{carion2020} site position loss (solving permutation invariance), TF classification cross-entropy, and slot diversity regularization. We use chromosome-based splits (chr1--17/18--19/20--22,X) and evaluate on ENCODE ChIP-seq for 7 TFs in K562 (CTCF, GATA1, TAL1, MYC, MAX, SPI1, CEBPB), spanning zinc finger, GATA, bHLH, ETS, and bZIP families (28,812 train / 1,533 val / 1,197 test sequences).

\section{Results}

\caption{\textbf{BEACON vs.\ BPNet.} (A)~Per-TF profile Pearson $r$: BEACON (single model) outperforms BPNet (7 per-TF models) on all 7 TFs. (B)~Binding site enumeration is 419$\times$ faster than BPNet+TF-MoDISco.}

BEACON achieves mean profile Pearson $r=0.901$ across 7 TFs, surpassing BPNet ($r=0.813$) on every TF (Fig.~\ref{fig:bpnet}A) with a single unified model (850K params) versus BPNet's 7 per-TF models (997K total). The largest gains are on bHLH factors (TAL1: $+0.18$, MYC: $+0.15$), where multi-TF modeling captures co-binding patterns. Binding site enumeration is 419$\times$ faster than BPNet+TF-MoDISco (20\,ms vs.\ 8.4\,s per sequence; Fig.~\ref{fig:bpnet}B). Site detection achieves F1${}=0.984$ and per-TF classification reaches 75.5\% (5.3$\times$ chance), with within-family confusion (e.g., MYC--MAX) 3.2$\times$ higher than between-family, reflecting genuine biological similarity (Table~\ref{tab:results}).

Crucially, BEACON's per-slot outputs directly enumerate binding events without post-hoc analysis (Fig.~\ref{fig:interp}A): each active slot reports \emph{where} a TF binds, \emph{which} TF it is, and \emph{how strongly}, with slot attention maps showing sharp focus on individual binding sites. Gradient-derived per-slot motifs recover canonical JASPAR PWMs (mean Pearson $r=0.55$; CTCF $r=0.78$, TAL1 $r=0.76$; Fig.~\ref{fig:interp}B), confirming biologically meaningful slot specialization. Ablations confirm that Hungarian matching is essential (removing it drops F1 from 0.98 to 0.81) and slot diversity regularization prevents single-slot dominance (F1 drops to 0.72 without it). Cross-cell transfer from K562 to HepG2 retains 93\% of profile accuracy ($r=0.84$) and 87\% of site detection performance.

\section{Significance}

BEACON introduces a new paradigm for TF binding analysis: rather than predict-then-interpret, it directly decomposes regulatory sequences into discrete, interpretable binding events via slot attention. The framework outperforms BPNet on profile prediction (+8.8\%) while providing inherently interpretable outputs 419$\times$ faster than post-hoc attribution pipelines, with strong cross-cell-type generalization. BEACON demonstrates that object-centric deep learning, successful in vision for decomposing scenes into objects, transfers effectively to genomics for decomposing regulatory regions into binding events.
